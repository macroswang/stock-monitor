# 观量 · Stock Monitor

本机独立运行的沪深 A 股分钟量规则监控客户端。Mac / Windows 共用界面及规则核心，无需自建服务器。只提供提醒，不连接券商、不读取持仓、不提交委托。当前版本为 0.5.0。

## 当前交付与验收边界


已实现自选添加/移除/暂停、日K及分时分钟量、规则判断、事件记录、范围下载和SQLite缓存、数据库备份、托盘后台运行、登录启动选项、本机通知、Bark配置及测试入口。

本地 Mac Apple Silicon 应用已构建；已完成87项核心测试、16项界面测试及本机安装升级验证；尚未完成整交易日连续运行验收。Windows 构建脚本和 CI 已提供，尚未在 Windows 主机执行，不能视为已有通过验证的 Windows 安装包。iPhone 需用户安装 Bark 并填入设备密钥后进行锁屏实测，尚未认证手机送达。

今天（2026-10-18）为周日，只显示历史缓存；没有把历史样本作为实时行情。随附12只自选、2026-10-16样本，历史触发共19次。实时行情标签完成口径、连续交易日稳定性及真实涨停再开板仍待实测，本版不能宣称已完全替代同花顺实时观察。

## 使用

1. 打开 Mac 应用“观量”。首次启动自动建立独立数据目录，导入12只自选及已核对历史缓存。
2. 输入六位股票代码添加自选，左侧选择股票查看分时量或日K；切换日期查看缓存。
3. “历史回放”使用已验证的历史涨停价/样本计算结果，只保存回放记录，不发送通知。新下载分钟数据如缺少认证历史涨停价，回放明确阻止，不猜测特殊股票涨跌幅。
4. 交易时段自动轮询行情，每轮完成后等待8秒，4只并发；实际采样间隔还包括请求耗时。启动时也会刷新一次行情；日K由独立任务检查本地缓存，15:15后按需增量补取已收盘日，不再每5分钟抓取一年。报价刷新不会重新下载日K。行情超过30秒视为过期；分钟数据超时、缺口或获取失败暂停相应判断。
5. “设置与通知”中点击“授权并测试本机通知”。可选择登录电脑后自动启动，默认不注册登录启动。
6. 关闭窗口后保留托盘/菜单栏监控；完全退出请使用托盘菜单“退出并停止监控”。电脑必须开机、联网且不休眠。
7. 数据管理按范围下载。分钟接口仅覆盖最近数日，无法取得的日期保持未知覆盖。日线按年度拆分请求；未复权，日成交量统一为股并以万股显示；保留原始来源单位。分钟量统一为股，分时图表换算为手。
8. “备份本地数据库”在数据目录生成一致性 SQLite 备份。恢复时先完全退出，保留原库副本，再用备份替换 monitor.sqlite3；不要在程序运行时替换或保留旧 WAL/SHM 配对文件。自动恢复向导尚未实现。

Mac 数据目录：`~/Library/Application Support/com.xreddot.stockmonitor/`。Windows 使用 Tauri 应用数据目录，界面“数据管理”显示实际路径。开发核心可用 `STOCK_MONITOR_DATA` 指定独立测试目录。

## 使用变化

- 相对触发浮窗新增做T扣费试算：默认2000股、佣金万2，最低佣金暂按每笔5元（可改）；分别计算双边佣金、卖出印花税、双边过户费和可选滑点。费用参数可展开编辑并保存在本机，佣金含过户费时可避免重复计算。仅按标记价卖出、悬停价买回的等量价差估算；悬停早于基准时只比较价格，不作为可执行做T。

- 自选列表展示最新报价、相对昨收的涨跌额与涨跌幅、当日振幅（最高减最低后除以昨收）；字段缺失时显示“—”。隐藏“买点研究”菜单入口。

- 分时图默认选中最近一个已确认“触发”标记，以该标记所在分钟价格为基准；鼠标移动时浮窗显示相对涨跌幅。手动点击其他触发后固定基准，点击“恢复最近触发”回到自动选择；切换股票或日期后重新默认选择。


- 分时“触发”标记仅在后两完整交易分钟严格缩量、符合原有触发条件后显示，固定标在顶部量所在分钟；后续更大量不会移动已有标记。仍封涨停时遵循原规则等待开板。

- 触发记录显示中文名称、代码、三分钟量（万股），支持按股票及日期范围筛选。
- 分时图显示蓝色价格线、黄色均价线；均价＝当日累计成交金额÷累计成交股数（含集合竞价）。浮窗显示均价；旧缓存缺少成交额时提示，近期行情更新后补充，不以收盘价格平均代替。
- 日K下方的横向交易日状态卡片列表已移除，日期通过日K点选和方向键切换。
- 日K上方的“上一交易日／日期／下一交易日”导航栏已移除，保留键盘与双击操作。
- 主图使用“分时／日K”Tab。点击日K选中交易日，左右方向键移动；缓存边缘先加载本地历史，缺失才按需请求相邻年份。双击日K或回车切换至当天分时；返回日K保留选中日与浏览窗口。价格保持元，成交量显示万股；浮窗使用中文。
- 日K持久缓存，历史请求按年分段、串行且间隔至少1秒，近期重复/重叠区间12小时内、较早区间7天内复用请求结果，失败区间1小时内不重试，重启后仍生效。不承诺公开接口绝不限制访问。批量指定范围下载保留在“数据管理”。
- 数据管理新增“最近20个交易日 · 分时缓存完整性”：按本地日K已有交易日期列出齐备、部分和缺失，以及数据来源，点击可进入当天分时。启动及收盘后低频补取，腾讯为主，新浪仅按整日补充缺失历史，不覆盖腾讯、不拼接分钟。成功请求通常12小时内复用，新交易日收盘后允许补取；失败冷却1小时，源请求串行至少间隔1秒。历史不按20日窗口删除。
- 新浪09:31含集合竞价且分钟边界与腾讯有差异，暂仅展示分时，规则回放未认证。部分日期缺少分钟时不补零，不跨缺口计算均价。
- 腾讯历史分钟仅返回最近数日，较早日期可能只有日K。进入缺少缓存的分时日期会按需尝试补取，并显示来源本轮覆盖说明；可一键返回最近可用分时。重复或失败请求30分钟冷却，重启仍生效；既有分时直接读取本地。缺少分钟或可靠历史涨停价会明确提示；历史回放不会推送。触及涨停的历史分钟收盘数据不能排除短暂开板后回封。
- 消息中心保留实时提醒及通知测试的内容、时间和提交状态，支持已读与跳转对应分时。旧提醒会迁入，已提交通知不会重发。
- 展开“数据来源”可查看供应商、实际公开接口地址与缓存覆盖；实时主来源仍为腾讯，新浪已接入历史补充，不能切换为实时监控来源。

## iPhone 锁屏提醒

先从官方渠道安装 [Bark](https://bark.day.app/)，启用通知，在桌面设置页只填写设备密钥，不填完整 URL。密钥保存到 macOS Keychain / Windows 凭据管理器，不写入SQLite，也不返回界面。点击测试按钮，随后在手机锁屏实际确认。

实现调用固定 HTTPS `https://api.day.app/push`，仅发送股票、日期、触发时间、三分钟量及规则原因。[官方接口](https://github.com/Finb/Bark/blob/master/docs/en-us/tutorial.md)。不上传完整自选池或缓存。默认关闭手机推送，启用后不补发此前积压事件。

推送记录 accepted 仅代表服务接受；没有手机送达回执。失败最多尝试3次，超3分钟过期。关注 iPhone 通知权限和专注模式。两台客户端同时运行暂不做跨设备去重。

## 规则

版本 `running_max_inclusive_v1`，分钟标签09:31–11:30、13:01–14:56。正分钟量 >= 截至当时最大量成为候选（含并列）；后两完整交易分钟分别严格小于候选量则确认。确认价格未涨停触发；仍涨停则等待随后首次观测到的低于涨停价格。日终失效，午休衔接，缺口阻断，未结束分钟不参与。

`core/validated_engine.py` 原样复制已核对验证器，仅供历史回归。`core/rules.py` 是流式核心，使用当时已知的分钟和价格；不使用未来全天最高价。腾讯分钟缺少分钟高低价，候选触板状态记录为未知；确认价低于涨停本身足以满足后续低于涨停观察条件。实时等开板使用时间戳新鲜的采样价格，不捏造逐笔成交或精确首次开板秒数。短暂开板可能漏采。

启动/恢复时完整重放当天前缀，历史事件标记 recovered，不实时推送；持续观察间隔超过45秒也进入恢复。事件以交易日+股票+候选分钟唯一去重，SQLite持久化。本机通知通过持久队列记录提交结果，重启不会重发已接受的事件；若恰在系统提交中断，结果标记未知，不擅自重复。历史回放、补取和实时事件分别记录。

## 开发与构建

需要 Node 22 LTS、Python 3.12、Rust stable。Windows 另需 Visual Studio C++ 构建工具和 WebView2；Mac 需 Xcode Command Line Tools。使用隔离虚拟环境安装 `requirements.txt`，`npm ci` 安装前端依赖。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm ci
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/package_core.py
npm run desktop
```

Mac：`scripts/build-mac.sh`。Windows：PowerShell 执行 `scripts/build.ps1`。CI定义位于 `.github/workflows/build.yml`，以本项目为独立仓库根目录使用。推送会触发Mac与Windows构建，结果以GitHub Actions为准。

内置Python核心通过stdin/stdout JSON行协议通信，安装包自带Python运行时，无需用户安装Python，无监听网络端口。开发工具链 `.toolchain/` 仅存在项目目录，不更改全局Rust配置。

浏览器预览：`npm run dev`，仅允许读取明确标注的历史预览数据，不能监控或发送通知。UI测试：先启动预览，`npx playwright install chromium` 后执行 `npx playwright test`。

## Mac 安装升级

当前已验证平台为 Apple Silicon、macOS 15及以上（实机验证为macOS 26.6.2）。构建后执行 `sh scripts/release-mac.sh` 生成独立DMG。尚未进行Apple Developer ID签名及公证。

升级时运行DMG内的“安装或升级观量.command”。程序备份数据库和旧应用，核对自选、缓存、触发和消息数量，再安装到 `/Applications/观量.app`，将用户Applications目录的旧入口指向新版。只处理这两个标准安装目录，不自动整理其他路径的旧副本。升级备份保存在本机数据目录的 `upgrade-backups` 子目录；数据库不会随源码或安装包分发。

日K支持使用现有实时行情生成当天盘中蜡烛，收盘后由完整日线替换；历史日线低频更新并长期本地缓存。页面操作提示5秒后自动关闭，消息中心历史记录保留。新浪历史补充分时只供查看，不用于已认证规则触发；实时监控主来源仍为腾讯。

## 大盘对照

顶部连续展示上证指数、深证成指与创业板指的最新点位、涨跌点数、涨跌幅及来源时间，过期报价标为最近报价。共享指数任务每30秒更新一次，休市时保留最近值；切换股票只读取本地缓存。

分时图以亮蓝粗实线展示个股、黄色展示均价，上证采用较淡灰色虚线。上证点位按双方各自昨收的涨跌幅映射到个股价格轴，仅匹配同日同分钟，不插值缺失分钟；浮窗显示实际指数点位与涨跌幅。缺少对应日指数分时或可靠昨收时明确提示，指数不参与股票卖点规则。

## 买点历史研究（不发送实时通知）

“买点研究”页对选定自选与日期的本地腾讯缓存执行固定 strong_pullback_v1。按完整分钟逐步识别上涨段、缩量回踩及再次转强；候选、确认与失效分别记录。研究结果不写入卖点事件、消息或推送队列，不改变卖点规则。

支持覆盖清单、强势上涨／完整V1／V1加指数三组对照、按可用分钟日期先后60%与40%分组、完整与部分日分组、日线趋势分组、下一完整分钟收盘代理及双边滑点敏感性、可选往返总费用基点、失败案例和分时研究标记。科创板使用上证代理基准时标注。没有足够数据时不认证策略有效。

“回放并导出报告”将HTML、JSON与五份CSV保存到本机数据目录 buy-research 内。文件可能包含个人选择的股票池，不随源码或安装包上传。
