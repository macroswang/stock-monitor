## 结论

- StockAPI 的 `blockFundFlow` 文档注明交易日 16:30 更新，属于盘后数据；不能当成盘中资金异动源。2026-10-31 约 21:19（北京时间），无 Token 请求板块资金、板块列表、板块成分返回代码 88886，内容称公共免费调用次数已用完。板块资金请求 HTTP 200 不代表业务成功。没有获取到可验证的样本。
- 同花顺 SuperMind 官方列有五分钟股票资金数据，以及历史资金接口 `get_money_flow_step` 的 5m 步长；文档支持研究其字段和回测。**尚未证实该接口在盘中提供当日数据，也未证实存在可直接用于本项目的实时全板块资金接口。**
- iFinD 官方 FAQ 指出 macOS 可使用 HTTP 数据接口。官网免费额度页面称需 iFinD 账号；FAQ 对免费账户描述与此存在差异：称免费账户面向购买 iFinD 终端产品的用户。个人申请条件、指标权限、所需费用和可在观量展示的许可需向同花顺确认，不能据此断定普通同花顺看盘账号有权限。
- 当前没有可用 iFinD 接口账号或 StockAPI Token；未进行认证接口试用。未实测盘中延迟、缺失率、稳定性、来源独立性及各方口径的一致性。

## 具备访问权限后的验证要点

1. 先确认是否提供沪深行业和概念盘中资金；如果只有个股 5 分钟数据，确认板块成分、分类和可授权聚合的口径。
2. 在交易日连续采样，分别记录真实行情时间、采集时间、完成分钟、请求成败、缺失或重复；计算 P50 / P95 / 最大延迟，不把轮询周期等同实际延迟。
3. 按同一代码与同一时间，对照价格、成交额、分类及资金口径；保留 API 返回与同花顺客户端的时间差和计算差异，不把客户端显示作为完全独立的源。
4. 核对覆盖范围、接口限流、历史成分与停牌处理、个人使用及桌面应用展示许可；接口授权凭据只存安全位置，不写入文档、前端或代码库。
5. 测试完成前，不更换现有数据源，不将新数据用于正式信号或自动交易。
