# 底／顶 Q1 冻结版

2026-10-25，用户选择将质量筛选候选Q封板并应用到分时图，替换旧v3及补漏层。只影响观察标记，不自动交易或通知。

识别沿用20个完整交易分钟背景、2—5个完整分钟反向确认；底偏离候选时累计均价至少0.8%、顶至少1.5%，原反转幅度及量能条件不变。同方向保留30个交易分钟间隔，不设每日数量配额。前一个顶之后的新顶仍需价格推进和更强回落。

接纳信号前检查：1000股分别不超过当时已知近5个完整分钟均量与当前分钟量的1%；按固定研究成本，确认价到当时累计均价的假设净空间至少0.2%。均价不保证到达。拒绝候选不更新间隔、计数或前顶条件。

研究成本：佣金每侧万2、最低5元；卖出印花税万5；过户费每侧十万1；每侧滑点取0.01元与价格0.05%的较大者，按不利方向取整分。与用户做T计算器设置无关。主历史执行假设为有1000股原有可卖底仓，在下一完整分钟收盘价代理成交，依原对向顶信号或预设14:56退出；没有移植失败的QR固定目标/止损方案。底／顶不是自动买卖指令。

历史口径：主历史220笔、94笔净盈利，胜率42.73%、每笔净收益率均值+0.2466%；其他已用日期7笔、2笔净盈利，胜率28.57%、均值-0.6691%。全部已参与过研究，并非新的独立验证。去掉最好日期后主历史净均值为负，未证明稳定盈利。不得把显示版本封板写成收益验证通过。

`freeze.json`保存规则、实现及研究来源哈希；`backtest-summary.json`保存原Q候选的六种成本/延迟情景。版本移植已逐点对照2151股日、524个标记，并进行704次前缀/未来扰动检查与121组成本边界比较。

正式顶部量触发、开盘量、通知、数据库、双底冻结条件、原有V3/L/LC新日期验证与两项定时任务均不改变。标记放在确认时刻，候选时间只供浮窗解释；点击标记不改变正式触发基准。旧补漏偏好不再叠加标记，显示开关继续保留并在主分时与关联分时同步。
